Política de privacidade

Melhor Preço Bloqueador (MP Bloqueador), extensão para Google Chrome

Resumo

O MP Bloqueador não coleta, não vende e não envia seus dados para ninguém. A extensão não tem servidor próprio, não usa ferramentas de análise de uso e não mostra anúncios. Tudo o que ela guarda fica no seu navegador, no seu computador.

Última atualização: 3 de novembro de 2026.

Esses dados ficam no armazenamento local da extensão no Chrome. Não são sincronizados com a sua conta Google nem enviados a nós ou a terceiros.

Quando a extensão usa a internet

  • Listas que você importar por endereço: se você adicionar uma lista de filtros pela opção "Importar", a extensão baixa essa lista do endereço que você informou e a atualiza de tempos em tempos. Nenhum dado seu é enviado nesse pedido além do que qualquer download comum envia.
  • Atualizações da extensão: são feitas pela própria Chrome Web Store.
  • Relatar problema: o botão abre uma página do GitHub com o endereço do site e a configuração da extensão já preenchidos. Nada é enviado sozinho: você vê o conteúdo e decide se publica. O GitHub tem a própria declaração de privacidade.

Crianças, venda de dados e seus direitos

Como não coletamos dados pessoais, não há dados para vender, compartilhar ou entregar. Os dados guardados no seu navegador podem ser apagados a qualquer momento: pelo botão "Limpar estatísticas", pela opção de restaurar o padrão nas Configurações ou removendo a extensão. Isso atende à Lei Geral de Proteção de Dados (LGPD), já que nenhum dado sai do seu dispositivo.

English summary

MP Bloqueador does not collect, sell or transmit any personal data. It has no server and no analytics. Settings and, only if you enable them, blocking statistics (kept for at most 30 days) are stored locally in your browser. The extension only downloads filter lists you import yourself. Questions: GitHub issues.
